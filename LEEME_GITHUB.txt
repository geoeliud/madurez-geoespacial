MMGI v0.15 — LISTO PARA GITHUB PAGES

Qué cambia respecto de v0.14
- Se mantienen las 5 fases, 25 habilitantes, 50 verificables y los resultados institucionales.
- Se muestran etiquetas de las 9 vías estratégicas IGIF en las fases, habilitantes y verificables.
- La vista Metodología incluye una leyenda completa de las nueve vías.
- La Tabla Maestra de la web y la autoevaluación muestran la correspondencia IGIF.
- Se incluye documentos/Correspondencia_IGIF_v0.15.csv con las 50 correspondencias.

Para actualizar GitHub Pages
1. Subir/reemplazar index.html en la raíz del repositorio.
2. Subir la carpeta documentos y Tabla_Maestra_Madurez_v0.14.xlsx.
3. Hacer Commit changes. GitHub Pages se actualizará automáticamente.

Seguridad
Este paquete público no incluye la carpeta de insumos internos ni la planilla de contactos.

Nota
La tabla Excel base de resultados permanece sin recalcular desde v0.14. La v0.15 añade la capa IGIF en la interfaz, exportaciones individuales y CSV de correspondencias.
